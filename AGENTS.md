# HomeLab public review baseline

This is a candidate public baseline, not an export of an installed HomeLab.
Read docs/operations/modular-cli.md before changing deployment configuration.
The catalog records 44 repository declarations; runtime is unknown. Only entries
marked renderable have portable Compose preview templates. Only fresh-project installation is supported after checks and specific
--execute; no destructive reset executor exists. Validate with synthetic data and mocks first.

Never read or publish secret values, .env, auth settings, databases or personal
documents. Keep site overrides and manifests private. Never start/pull/build,
delete data, migrate, change network policy, commit unrelated work or push without
specific authorization. Use small scoped PRs and preserve all preexisting work.

Always preserve non-target databases and music. Reset scope requires current
private manifests, consumer/process checks and per-group human review. No prune,
no project-wide down-v and no generic database name matching. A preview does not
authorize operations. Private LAN/tailnet routes belong to the local installation.
